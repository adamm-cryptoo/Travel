# TapTravel
Static site in HTML, CSS and JavaScript. No build step.

Open `index.html`, or run it with the VS Code "Live Server" extension.

- `js/data.js`: destinations, prices, Black Friday codes and each destination's theme
- `js/main.js`: header/footer, theming, filters, estimator, booking dialog
- `css/style.css`: layout and theme variables

To add a destination, copy one object in `D` and change its fields and colours.
